# Defect Detector

Система визуальной инспекции для Linux.

- `orchestrator-java/` — захват кадров, управление камерами, светом, DI/DO,
  обмен с ПЛК, API и координация инспекции.
- `cppAnalisSurface/` — C++-анализатор поверхности и шва (OpenCV, HTTP/SHM).
- `front-end/` — интерфейс React и Electron-киоск.

`camera-worker/` содержит JNI-библиотеку камер для оркестратора;
`config.exemple/` — пример конфигурации; `plk/` — карту регистров ПЛК;
`deploy/` — установку, управление и диагностику Linux-системы.

Цикл: аппаратный триггер → захват через JNI → C++-анализ → решение → ПЛК и UI.
