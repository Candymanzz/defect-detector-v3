(`d1ac431a`), включающий `fix-anomali-score` (`2fd1365e`).

Перенесены изменения e4fe289a, 946c172a, 2fd1365e, 20e8c4b2 и bfd9b54a:

интеграцию от исходной основы; исходная ветка не изменена.

## Настройки

Score достигает 1.0 при аномальной площади 0.2% ROI. Новый порог по умолчанию —
0.6. Сохранённые пороги не переписываются: после обновления проверьте их на
рабочих эталонах с учётом новой шкалы.

Старый `shift_tolerance` принимается и задаёт обе оси. Явные
`shift_tolerance_x` и `shift_tolerance_y` имеют приоритет.

В шаблоне config.exemple UI использует 2 фоновых потока и defer_heatmap=true.
Рабочий config оборудования автоматически не заменяется. При явном
`defer_heatmap: false` сохраняется синхронная генерация heatmap.

## Проверка

- Frontend: production build и 63 теста Vitest.
- Java: чистая сборка, 400 тестов (4 пропущены, без ошибок).
- Linux-скрипты: 21 тест; camera-worker: 2 теста CTest.
- C++: сборка с OpenCV 4.6, httplib 0.14.3, nlohmann/json 3.11.3 и CTest.
- Java → C++: CppDetectorLinuxIntegrationTest с HTTP, SHM, изоляцией эталонов
  камер, multipart, новым порогом и совместимостью допусков X/Y.

Для тестовой сборки недостающие header-only зависимости размещены в
/tmp/kal-httplib, конфигурация CMake использует
`-DCMAKE_PREFIX_PATH=/tmp/kal-httplib`. В репозиторий зависимости не добавлены.
Тесты HTTP требуют разрешённых локальных сокетов.
Проверка физического оборудования и производственных кадров не выполнялась.
