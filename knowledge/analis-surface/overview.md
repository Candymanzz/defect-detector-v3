## 1. Purpose
Compares the current frame with a stored **reference** per camera-scoped product (`<product_type>#cam=<id>`), builds a difference map, extracts defect components and returns a verdict **`ГОДЕН` / `БРАК`** with score (0..1), threshold, per-sub-zone scores, FP‑zone and learned-normal adjustments, timing, and an optional gray‑u8 **heat-map** (SHM). It also owns per-product **ROI polygon, perspective line, ROI sub-zones, FP zones**, **analysis settings** (with the 0..100 % knob model) and the **learned acceptable normals** memory with an operator “learning review” UI.

## 2. Stack & runtime
Python 3, FastAPI + uvicorn (`A:main.py`), OpenCV (`opencv-python`), NumPy, Pillow, httpx, PyYAML (`requirements.txt`; **no anomalib/PatchCore any more**, removed `db7e2961`). Tests: pytest (`pytest.ini`, marker `integration`), ~384 pass.
The checked-in configuration launches **6 processes** on ports 8000‥8005 (`AnalisSurfaceLauncher`, command from `analis_surface_command_linux`: `tools/run-analis-isolated.sh -m uvicorn app.main:app --host 127.0.0.1 --port N` — wrapper script is not in git). This count is configurable. Env: `ANALIS_INSPECT_WORKERS` (the launcher template requests 3; Python fallback is 10 if unset, clamp 1‥32; `A:api/dependencies.py:~20`), `PY_POSITIONING` (default on), `PYTHON_APP_ID`/`DETECTOR_ID`.
`cv2.setNumThreads(1); cv2.ocl.setUseOpenCL(False)` (`dependencies.py`): parallelism comes from the process pool, not from OpenCV teams (avoids oversubscription when 10 cameras arrive together).

## 4. Pipeline `_inspect_frame_unlocked`
<a id="pipeline-_inspect_frame_unlocked"></a>
`S:inspection_service.py:1066-1714` (entry `inspect_frame:1052` takes the per-product lock). Steps with log stage names (`log_analysis_stage`):
1. **Settings**: `AnalysisSettings` for `analysis_profile or product_type`; temporary overrides (`analysis_test_settings`) merged over saved overrides; `threshold` request value wins over `default_threshold`.
2. **Reference** `self.references[product]` (RAM) must exist else `ValueError` ⇒ HTTP 400.
3. **Positioning** (`stage alignment`, :1103-1122): if `PY_POSITIONING` → `FramePositioner.position(frame, reference, roi_polygon, reference_token)`; else `_use_fixed_frame` (resize if sizes differ). Algorithm: high-pass (σ=3) float gray of the ROI box (+4 % pad, ≥16 px) downscaled to ≤640, `cv2.phaseCorrelate` with Hanning window; accepted only if response ≥0.08, shift ≥0.15 px and ≤32 px, and a clipped (30) mean-abs-error check on overlapping pixels improves by ≥1 % (`after < 0.99·before`); applied as `warpAffine` translation (`BORDER_REPLICATE`). Statuses: `ok, unchanged, low_texture, low_confidence, shift_too_large, already_aligned, no_improvement, small_roi, cv_error:*`.
4. **Downscale pair** `_downscale_aligned_pair` when `inspect_scale_after_align<0.999` (frame & reference resized together).
5. **ROI mask** (`roi_mask`): `mask_to_polygon` zeroes outside the polygon for scoring; the *difference* is computed on a crop with **48 px padding** (real context, avoids an artificial black border).
6. **Difference map** `_compute_advanced_difference:2899-3235` (stage `diff_map`/`illumination`), details in §4.1.
7. **Anomaly model** `_run_anomaly_model:3500-3715` (stage `anomaly_detection`), details in §4.2 → `(raw score, BGR segmentation mask)`.
8. **Learned normals** (`learned_normals`): `AcceptedNormalMemory.apply(product, ref_hash, aligned, diff_map, mask)` removes components matching operator-approved cases; if anything matched ⇒ re-score (`learned_score`); if all important candidates matched and no significant/guarded residual and score < threshold ⇒ sub-zone check then optional zero-out (:1226-1272).
9. **FP zones** `_recheck_fp_zones:2313-2509` (stage `fp_recheck`): zone polygons are punched out of the score; zones that "triggered" (`diff_q90 ≥ fp_trigger_diff_q90 (22)` or `active_ratio > 0.01` or `score ≥ 0.08`) are compared against the stored mini-etalon crop; matches (`note "matched FP mini-etalon"`) are excluded and reported as `excluded_normal_zones(kind fp_zone)`.
10. **Regional scoring** `_score_inspection_regions:1716-1772` (stage `regional_scoring`): main ROI region (minus sub-zone holes) + each sub-zone with own threshold; `_score_region:2144` = `max(_run_anomaly_model on masked diff, activity score)`; `anomaly_score = max(zone scores)`; **`БРАК` iff main ≥ threshold or any sub-zone ≥ its threshold**. `_activity_score = 0.45·q90/255 + 0.15·max/255 + 0.30·√active_ratio`.
11. **Visuals** (only if `include_visuals` or heat-map requested): `_build_heatmap_gray(mask, diff)`, clipped to ROI; colourisation + overlays only for the legacy `/inspect*` paths. Production returns gray‑u8 into SHM.
12. **History / learning review**: new `uuid` `inspection_id`; review task (aligned, diff, raw mask, candidates, geometry context `evidence_revision "compact-structure-v4-curvature"`) stored synchronously, or queued to `_DeferredLearningReviewWriter` when `defer_learning_review` (queue full ⇒ dropped, `inspection_id=None`).
13. Result `InspectionResult` (with `py_align_ms, py_diff_ms, py_anomaly_ms, py_fp_recheck_ms, py_heatmap_ms, py_total_ms`; `deferred_heatmap_data` when `defer_heatmap`).

### 4.1 Difference map (`_compute_advanced_difference`)
Gray conversion (reference gray cached) → optional **pre-normalisation compact signal** (`pre_normalization_compact_signal`, raw island evidence before light compensation) → **smooth illumination suppression** (`_suppress_smooth_illumination`, constants `_ILLUMINATION_MIN_SHIFT 6, FULL_SHIFT 22, DETAIL_SCALE 18, GRADIENT_SCALE 32, LOCAL_MAX_SUPPRESSION .30, BROAD_MAX_SUPPRESSION .75`: removes shadow/glare fields, returns per-pixel *confidence*) → CLAHE (`clahe_clip_limit>1.05` and `std>5`) → **shift-tolerant envelope** (current vs local min/max of reference: `over = cur − ref_max`, `under = ref_min − cur`, 5×5 envelope, 2 px displacement allowance) → bilateral(7,35,35) + Gaussian 3×3 → **BlackHat+TopHat** (15×15, weights .6/.2/.2) → far-side **detail response** weighted by `far_weight` → **vertical/perspective gain** (`far_edge_max_gain × width_scale`, first 65 % of the ROI neutral, last 35 % ramps; `_FAR_TIP_EXTRA_GAIN_LIMIT .5` extra on the final 10 % only where compact evidence confirms) divided by illumination confidence → **stable-edge suppression** (Canny 80/160, only edges present in *both* reference and current; factor `edge_suppress_factor`, `far_edge_edge_suppress_factor` toward the far side) → **contrast-loss boost** (`ref_grad>contrast_loss_ref_grad ∧ cur_grad<contrast_loss_cur_grad`: missing print/structure ×`contrast_loss_boost`) → **text/structure mask** (reference structure `> text_structure_threshold` requires `≥ text_min_contrast` unless contrast-loss) → merge **compact raw evidence** (max) → BGR.
### 4.2 Anomaly model (`_run_anomaly_model`)
`compact_residual_evidence` (shape/noise-confirmed compact islands) → if `max(gray_blur) < min_diff_signal` return it. Threshold `max(min_diff_signal, min(percentile(gray_blur, diff_percentile), 35))` → median 3 → keep far-side thin traces (`far_weight ≥ .5` and ≥3 neighbours) → close 3×3 and directional closes 7×1 / 1×7 (bridge small breaks only) → connected components. Per component: area filter (`min_defect_area`, 5 for aspect>6, relaxed by perspective scale), keep elongated tiny ones (`aspect > min_scratch_aspect`, area>3); score = `(min(aspect/15,1)+min(area/500,1))·signal + q90/255·.25 + compact_support·q90/255·.8`, ×1.3 if text overlap>0.2, +0.4 for lost reference structure; per-component scratch floor `scratch_score_floor·signal` when `aspect>scratch_aspect_floor`. **Scatter guard** (`_scatter_component_weights`; `scatter_min_components 6`, `scatter_min_cells 5`, grid 4×4, dominance ratio 2.5, `scatter_suppress_factor .4`): many thin deviations spread over the frame ⇒ residual misalignment, down-weighted. Final `score = clip(max_obj·0.55 + top2%mean·0.40, 0, 1)`, then `max(score, scratch_floor, compact_score)`.

## 6. Learned normals (operator-approved false positives)
`S:learned_normals.py`: `InspectionReviewStore` keeps the last `review_limit` (200) inspections (both ГОДЕН and БРАК, `972efdc0`) on disk with images (frame, heat-map, diff, mask) and extracted `DefectCandidate`s (`extract_defect_candidates:1419`, relevance filter `filter_review_candidates:1548`, `REVIEW_MIN_RELATIVE_IMPACT .15`, scratch variants). Operator accepts a candidate ⇒ `AcceptedNormalCase` (64×64 template of image/diff/mask, polygon, bbox, coordinate space, `reference_hash`) saved in `data/accepted_normals`. At inspection time `AcceptedNormalMemory.apply` matches new candidates to cases of the same product & reference hash by **position tolerance** (6 px + jitter floor 4; large objects up to 6 % of frame/≤25 px) and **shape similarity** (`GENERAL_MIN_SIMILARITY .80`, `REDUCED .78`, `SCALED .76`, `THIN_TRACE .68`; contour/overlap/angle/template metrics `candidate_similarity:1807`), suppressing only matched components (a new scratch inside a saved broad normal stays). Decision of an already-passed product is never re-sent to PLC; effect starts with next inspection. Cross-process consistency via a storage generation token (`_publish_storage_generation`, `_refresh_from_disk_if_changed`).
Docs: `analisSurface/docs/LEARNED_NORMALS.md`, `FP_LEARNING_*.md`.

## 7. Concurrency & background work
- `inspect_executor` (`InspectionExecutor`, threads `inspect-*`) increments `InspectionWorkload.foreground` **at submit** time; `BackgroundExecutor` (1 thread `heatmap`, capacity 4, max wait 3 s) runs deferred heat-maps and `_DeferredLearningReviewWriter` only when no foreground work has been queued/running and 25 ms of quiet passed ⇒ inspections always have priority (`BackgroundBusy` otherwise).
- Per-product lock `_product_lock` serialises inspections of the same `product#cam`.
- `fp_zones.generation` file token and analysis-settings signature keep six processes consistent.
