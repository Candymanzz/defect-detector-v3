# Коммит и объединение ветки перед push — 2026-11-05

## Исходное состояние

По запросу владельца «закоммить и запушь» обнаружено, что изменения
ExposureEnd и локальные заметки уже находятся в коммите **4b5e8efd**
(`light off <di2`). В рабочей копии начато, но не завершено слияние
с **37499f9e** из origin/boobs+pasha. Удалённая ветка содержит ещё
99671642, c201c27c и 37499f9e после общего fd442c97.

Код был автоматически объединён начатым merge. Конфликты остались только
в семи knowledge-документах: README, PROJECT_CONTEXT, архитектура,
known_issues, decisions, global_changelog и deploy-ops/overview.

## Решение

Продолжено существующее слияние, чтобы сохранить оба направления истории
и отправить результат обычным push. Принудительное переписывание истории
для этой задачи не применяется. Успешный fetch подтвердил удалённую вершину.

Конфликтующие дополнения заметок сохранены с обеих сторон; проверено,
что заголовки из обеих версий присутствуют после объединения. Перед
объединением сохранены исходные конфликтные файлы и index stages 1/2/3
в `.verification/commit-push-20261105/`. Новая запись сверху уточняет
состояние исходников и runtime, чтобы старые сведения о fd442c97
не воспринимались как описание объединённой версии.

В объединённых исходниках присутствуют:

- локальная выдача Off по ExposureEnd всех камер после проверки регулярности;
- DI3-only изменения из origin, устранение зависимости capture от DI2;
- исправления preprocessing/learning и ECC512-позиционирование из origin.

ExposureEnd wiring в TriggerRuntimeBootstrapService и параметры
off_on_exposure_end/exposure_end_validation_cycles в шаблоне сохранены.
Алгоритм ECC не исправлялся в этой Git-задаче. Его известное ограничение
на изменениях яркости сохранено в [отчёте](../analis-surface/2026-11-05-ecc512-prepush-validation.md).

## Проверки и ограничения

- Java `mvn -o -q -f orchestrator-java/pom.xml -Djava.awt.headless=true test`:
  **424 теста, 0 failures/errors, 15 skipped**. Для тестовых localhost-сокетов
  использовано исполнение вне песочницы. Лог:
  `.verification/commit-push-20261105/java-tests.log`.
- Нет конфликтных маркеров; проверены diff и сохранность заголовков обеих
  версий заметок. Изменённые/добавленные ссылки проверены локально.
- C++-изменения совпадают с origin/boobs+pasha; новый локальный C++-прогон
  не выполнен: private runtime содержит core/imgproc/imgcodecs, но не
  opencv_video, который требуется ECC. Не использовать старые Windows
  CTest из входящей ветки как подтверждение новой Linux-сборки.
- Native/lighting проверки и аппаратный замер относятся к 4b5e8efd:
  [35 циклов и пять ранних Off](2026-11-05-exposure-end-flash.md).
  Нативный event-код при слиянии не менялся.
- Backend не пересобирался в package и не перезапускался. Рабочие конфиги
  не менялись. Тестовая компиляция Java не заменяет работающий JAR.
  Источники после merge содержат новые DI3/ECC изменения, но работающий
  процесс продолжает прежнюю развёрнутую версию. Новый аппаратный цикл
  именно объединённой версии этим push не подтверждается.

После завершения merge отправляется ветка boobs+pasha обычным push;
результат проверяется сравнением локального HEAD с веткой на сервере.
