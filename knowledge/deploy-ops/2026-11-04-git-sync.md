Первый полный Java-прогон выявил старую непереносимость
`StackSupervisorMainTest.destroyProcessTreeTerminatesChild`: запуск `.sh`
через CreateProcess завершался ошибкой 193 на Windows. Этот тест и
производственный supervisor не менялись в upstream-коммите. Тест исправлен:
дочерняя JVM печатает готовность и ждёт, затем проверяется её завершение;
`finally` очищает процесс. Production-код supervisor не менялся.
После исправления полный набор прошёл с результатом в таблице.

Два невыполненных Java-сценария: Linux-only интеграция Java → C++ через
`/dev/shm` и проверка POSIX locale в JNI. Запускали JUnit launcher с теми же
зависимостями, поскольку Maven отсутствует в PATH; shaded JAR не собирали.
Логи проверок: `.verification/remote-sync-*.log` (игнорируются Git).
