# 2026-11-03 — Одна команда полной пересборки и перезапуска

**Задача:** создать `rebuild-and-run-all.sh` для быстрого обновления всего рабочего проекта.
**Решение:** новый исполняемый скрипт повторно использует `rebuild-and-run.sh` для Java,
C++, camera JNI и frontend. После успешной сборки перезапускает systemd backend,
ждёт C++/Java health и API дообучения через Java, затем перезапускает киоск.
**Почему:** существующий сборщик уже учитывает локальный runtime, Maven, MVS и установку UI;
дублирование расходилось бы с ним. Явный backend restart устраняет причину недавнего 404.
До сборки проверяется, что сервис запускается из того же checkout; сбой сборки не вызывает
перезапуск, сбой backend не вызывает перезапуск UI. Есть `--build-only`.

**Проверки:** Bash syntax/help и изолированная подстановка внешних команд подтвердили
порядок операций, обработку ошибок, build-only, аргументы, pkexec и пути с пробелами.
Реальная пересборка/перезапуск новым скриптом не выполнялись. Существующие настройки
и алгоритм приложения не менялись. [Использование и ограничения](deploy-ops/overview.md).

**Задача:** по запросу владельца перенести функции из D:/Pj/CppDetector в основной checkout;
исходная ветка lin-cpp-doob, HEAD 52aa31ea, базовое дообучение уже присутствует.

**Решение:** перенесён тот же matcher, интегрированы настройки профилей и overrides,
исходный matcher оставлен переключателем. Диагностика хранится в решении кадра, WS и архиве.
Совместимы старые данные и конструкторы Java. На Windows добавлена замена существующего JSON
через MoveFileExW; Linux rename сохранён. Историческая база восстановлена, расхождения помечены.

**Почему:** повторная реализация расходилась бы с проверенным стендом; повышение общих X/Y
ослабляло бы все сравнения. Привязка к решению кадра исключает показ диагностики другой инспекции.
Компромиссы: начальные ограничения тени не откалиброваны на станке, визуально одинаковый дефект
неразличим с обученной нормой, большие/многочисленные образцы дороже.

**Проверки и вывод:** основной C++ Release +5/5 CTest, HTTP moving-shadow/scratch/overrides/restart,
289 main+109 test Java compilation и 15/15 JUnit, frontend 72/72 Vitest +build прошли.
ESLint новых компонентов/настроек/типов прошёл; старый эффект геометрии ModalWrapper остаётся ошибкой
и воспроизведён на HEAD. Реальный браузер, Linux и оборудование не проверены; сервер не развёртывался.
[Подробный отчёт](analis-surface/robust-learning-v2.md).
