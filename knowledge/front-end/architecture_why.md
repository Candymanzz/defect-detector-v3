# front-end — architecture "WHY"

Back to [overview](./overview.md) · Evidence tags: **[doc]** **[code]** `⚠️ [GUESS/CONJECTURE]`.

1. **Electron kiosk, not a browser tab** — ⚠️ [GUESS/CONJECTURE] from `deploy/kiosk/{session.sh,defect-detector.desktop}`, `IML_KIOSK=1`, commits `17281a7c` “фикс продрачивания хромиума”, `2396fc5a`/`df90df97` “фикса экрана”, `3deef3bc` (2026‑10‑09). The industrial PC has a bare Xorg session with no window manager, so main.cjs sets display bounds manually (comment in `electron/main.cjs`) and blocks shortcuts/devtools/navigation in kiosk mode.
   - **GPU disabled** (`app.disableHardwareAcceleration()`, `--disable-gpu*`): fix for black screen/crashes on the RT machine (“fix for electron” comments); GPU child death reloads windows.
   - **Renderer recovery** limited to 3 per minute; OOM clears Chromium cache (comment: “A renderer OOM leaves an otherwise live BrowserWindow black”). Memory metrics every 60 s feed long-run diagnostics (`java` side has similar session logs).
   - Orchestrator treats UI process exit as a fatal event (see [orchestrator why §9](../orchestrator/architecture_why.md)); `session.sh` restarts Electron after 5 s.
2. **Reference library in the browser (IndexedDB)** — **[code]** `shared/referenceImages.ts`. The orchestrator stores only descriptors + durable SHM copies; the engineer's *named reference groups*, ROI contours, FP zones and approved learned cases live in the UI so a different reference can be re-applied without recapture (archived groups ≤24; commit `92ab0d84` “название эталонов, сохранение, редактирование”). Trade-off: per-kiosk state; copying a machine requires exporting IndexedDB (not provided) ⚠️ [GUESS/CONJECTURE].
3. **Staged commit of references** (`stageReferenceBundle*` → ack → `commitReferenceBundleImages`): the UI must not replace its stored reference until the server confirmed the bundle (`server.reference_bundle_ack.ok`); a rejected bundle leaves the previous reference intact (`ReferenceController.ts` ack handling). Preview is paused ≤15 s during submission (`REFERENCE_PREVIEW_PAUSE_TIMEOUT_MS`) so the bundle frames are not overwritten.
4. **Controller/hook split** (`MainController.ts`, `ReferenceController.ts`, `HeatmapController.ts`, `StreamController.ts`, `SettingController.ts` + `use*` hooks): pure logic is unit-testable; React components stay thin. ⚠️ [GUESS/CONJECTURE] team convention.
5. **Heat-map in a Web Worker** (`HeatmapRenderWorker.ts`; palette `2f5c576f`, `e4876da2`, `67f165c7`): orchestrator ships gray‑u8 (small) and the browser colours it with a normalisation LUT; decoding on the UI thread would stall interaction on the kiosk. `ImageBitmap` is transferred, not copied.
6. **Reduced image quality for UI only** (`4d7f01a9` “занизил качество для фронтенда”; YAML `inspection_preview_jpeg_quality 45`, card 30, heat-map width 384) — the detector keeps full-resolution frames; 10 cameras × updates on a single kiosk otherwise saturate the renderer/network. **[doc]** `30-ui-and-client.yaml` comments.
7. **Immutable artifacts + ordering guards**: result images are fetched by artifact id (cache-safe); `compareInspectResults`, `isInspectionCounterReset`, per-camera “accepted after” timestamps prevent late results of a stopped/restarted inspection from overwriting new ones (commits `d4752eff` “большой фикс по синхронизации результата инспекции”, `4215a559` indication of rejects).
8. **Live preview is blocked during inspection** (`8adf849c`, `931cc4bd`): capturing previews would contend with the hardware-triggered cycle and the camera streams are mutually exclusive with sync capture (worker rejects `capture` while streaming).
9. **TEST mode for settings** (commit `10bc8ca2` “сделал настройку анализа прямо на текущем кадре”, `c2c7e6b2`/`573835b1` python test service): changing sensitivity must be validated on a *pinned* frame without touching production verdicts/PLC. Therefore opening settings flips the server to TEST (`setTestMode(true)`), which also drops `vision_ready` (the line stops being “ready” while engineers tune).
10. **Simple/Pro settings with an access code** (`165b880b`): operators adjust threshold/sensitivity; engineers unlock six strengths. The code is a hard-coded UI constant (convenience lock, trivial to bypass) ⚠️ [GUESS/CONJECTURE] intent is to prevent accidental changes, not security.
11. **Oriented-rectangle seam ROI** — introduced in the big release commit `768f650f` (2026‑08‑03 “релиз: стык/геометрия, вспышки по DI2, COM в bank On/Off”: message “Усилен анализ шва и ROI, interval_flash по импульсу DI2, bank гасит Ethernet+COM”) together with `LabelSeamBandSegmenter` (+340 lines) and the rewrite of `LabelSeamAnalyzer` (±382) **[doc: commit]**; files `orientedRectRoi.ts`, `RoiContourEditor.tsx` (+316). Why: the geometry service derives the seam axis from the polygon's long side, so a rotated rectangle (axis + half-width) is the only accepted joint ROI shape; the geometry service derives the seam axis from the polygon's long side, so a rotated rectangle (axis + half-width) is the only accepted joint ROI shape (`isValidJointRoiPolygon` = exactly 4 points forming a parallelogram).
12. **Perspective line** (`436e74d6`, 2026‑10‑02): UI lets the engineer draw near→far on each view; sent in the bundle and carried by every inspect request to the detector (see [analis-surface why](../analis-surface/architecture_why.md)).
13. **Frontend update without password prompts** (`4616cb7a`): `rebuild-and-run.sh` copies `dist/`, `electron/`, `package.json` into `/opt/defect-detector-ui` through a restricted sudoers helper (`setup-frontend-updates.sh`); old hashed assets are retained until the kiosk reloads (comment in script).
14. **Fresh reference frames with the previous ROI** (`43ec2a9a`, retained by `3fcb91c3`) — **[code, operator requirement]** **«Новый эталон с прежним ROI»** captures only the selected camera group while preserving ROI/joint/perspective/FP geometry, then auto-submits after fresh frames and image URLs reach React state. Partial capture is not submitted; a server ACK is required for confirmation. This is separate from **«Новый эталон с новым контуром»**. It reuses the existing learned-case inheritance policy for a non-full replacement. See [the workflow and validation limits](../recent_context.md#3-replace-reference-frames-while-keeping-roi).
