# PLC register map (Omron MAP 25_247)

Исходные экспорты из CX-Programmer / MAP — файлы `25_247_MAP - *.csv`.

Для кода и конфига оркестратора используйте **`register-map.yaml`** — нормализованный список сигналов техзрения.

## Листы CSV

| Файл | Назначение |
|------|------------|
| Память.csv | Области памяти (CIO/D/W/H) |
| Входы.csv | Дискретные сигналы техзрения → ПЛК (W0.xx ← Xn) |
| Состояния-неисправности-управление.csv | CIO 140 / 190 / 240 |
| Зона 1/2/3, Общая зона | Логика линий |
| Настройки.csv | Таймауты отбраковки (DM) — **FINS** |
| Связь.csv | Внутренняя связка W↔T |

## Разделение каналов (как в MAP)

### FINS (только настройки)

| Адрес | Назначение |
|-------|------------|
| D4400 | Тайм-аут отключения контроля отбраковки |
| D4401 | Тайм-аут движения отбракованного ведёрка |
| D4402 | Тайм-аут толкания отбраковкой |
| D4403 | Тайм-аут звукового сигнала отбраковки |
| D4404 | Тайм-аут контроля цикла конвейера |

### Дискретные входы (техзрение → ПЛК)

| Логика ПЛК | Физический вход | MV IO DO |
|------------|-----------------|----------|
| 140.02 Техзрение готовность | **X4** | **DO1** |
| 190.00 Техзрение ошибка | **X5** | **DO2** |
| 140.08 Бракуем линию 1 | **X6** | **DO3** (импульс) |
| 140.09 Бракуем линию 2 | **X7** | **DO4** (импульс) |

DO5 = Line0 (съёмка). **CIO 240.15 не используем.**

Оркестратор → IoInputMonitor HTTP (`/vision-ready`, `/vision-fault`, `/reject`) → DO → X4–X7.
