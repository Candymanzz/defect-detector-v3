# Обучаемые допустимые фрагменты

Функция предназначена для постфактум-разметки ложных дефектов оператором.
Решение уже прошедшего изделия не переотправляется в оркестратор или PLC.
Сохранённый пример применяется только к следующим инспекциям.

## Операторское окно

После запуска FastAPI откройте:

```text
http://127.0.0.1:8000/learning-review
```

Страница показывает последние результаты `БРАК`, сохранённые текущим процессом
Python. Нажатие на карточку открывает кадр, heatmap, diff, mask и отдельные
контуры найденных областей. Кнопка «Считать выбранный фрагмент допустимой
нормой» сохраняет только выбранную область.

Операторский список не показывает малозначимые точки, чтобы они не загромождали
разбор. По умолчанию область показывается, если она достаточно велика по
площади, протяжённая хотя бы по одной оси либо маленькая, но очень контрастная.
Это только фильтр списка: скрытые точки по-прежнему участвуют в основной
инспекции и итоговом score.

Ниже на той же странице расположен список сохранённых норм с миниатюрами.
Кнопка «Удалить из списка нормы» сразу убирает выбранный пример из памяти и с
диска. Начиная со следующей инспекции этот пример больше не исключает дефекты
из итоговой оценки; перезапуск приложения не требуется.

Ознакомительный пересчёт старого кадра отображается на странице, но никуда
дальше не передаётся.

## Локальная проверка по двум изображениям

Для ручного теста без камеры и shared memory откройте:

```text
http://127.0.0.1:8000/local-inspection-test
```

На Windows можно ничего не вводить в консоль: дважды нажмите
`LocalInspectionTest.cmd` в корне проекта. Он запустит только Python-бэкенд,
если тот ещё не работает, и откроет эту страницу в браузере. Если уже запущена
старая версия Python, скрипт попросит сначала перезапустить `DefectDetector`.

Выберите эталон, текущий кадр и нажмите «Запустить проверку». Страница покажет
исходный и итоговый score, визуалы, найденные контуры и сохранённые нормы.
После сохранения или удаления нормы повторите проверку с тем же текущим кадром.
По умолчанию используется отдельный `product_type=local-test`, чтобы тестовые
нормы не применялись к производственным камерам.

## Поведение следующих инспекций

Каждая новая область маски сравнивается с сохранёнными примерами того же:

- `product_type` (в проде он уже содержит `#cam=N`);
- эталона (`reference_hash`);
- диапазона размеров.

Положение по кадру полностью исключено из similarity: один допустимый след
может перемещаться по изделию. Требуется одновременная близость формы по
симметричному расстоянию масок, локального diff и изображения. Один сохранённый
пример может исключить несколько похожих областей одного текущего кадра. Только
достаточно похожие области удаляются из `diff_map`/маски до расчёта итогового
score. Остальные дефекты продолжают формировать обычный `БРАК`.

Близкие части одного тонкого следа, разорванные порогом маски, объединяются для
сравнения в один логический фрагмент. Нижней границы размера нет: уменьшенный
вариант нормы может совпасть при сохранении формы и внешнего вида. Увеличение
ограничено `1.60`, поэтому значительно более крупный похожий дефект остаётся
браком. `learned_normal_matches_count` содержит число реально исключённых
областей, даже если все они совпали с одним сохранённым примером.

## Хранение

Подтверждённые примеры сохраняются в:

```text
backend/app/data/accepted_normals/
```

Для каждого примера создаются JSON-метаданные и сжатые NumPy-шаблоны. На старте
сервиса каталог очищается: после перезапуска ложняки предыдущей смены не
действуют. Архив инспекций пишется на диск (`learning_reviews/`) и по умолчанию
содержит последние 50 кадров — и `ГОДЕН`, и `БРАК` (FIFO). Лимит задаётся переменной:

```text
ANALIS_LEARNING_REVIEW_LIMIT=50
```

## API

```text
GET    /learning/reviews
GET    /learning/reviews/{inspection_id}
GET    /learning/reviews/{inspection_id}/image/{aligned|heatmap|diff|mask}
POST   /learning/reviews/{inspection_id}/defects/{defect_id}/accept-as-normal
POST   /learning/reviews/{inspection_id}/accept-all-as-normal
GET    /learning/accepted-cases
GET    /learning/accepted-cases/{case_id}/image
DELETE /learning/accepted-cases/{case_id}
```

`POST .../accept-as-normal` и `POST .../accept-all-as-normal` возвращают
`affects_original_pipeline_decision=false`.
Дополнительные поля обычного результата инспекции обратно совместимы:

- `inspection_id` — UUID кадра в сессионной истории (`ГОДЕН` и `БРАК`);
- `learned_normal_matches_count`;
- `learned_normal_adjustment`;
- `matched_accepted_case_ids`.
