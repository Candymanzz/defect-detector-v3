# Simple / Detailed — подписи и пояснения для UI

Готовые тексты для UI: **название на экране** + **короткая подсказка**.  
Технический маппинг: [ANALYSIS_SETTINGS_SIMPLE_PRO.md](ANALYSIS_SETTINGS_SIMPLE_PRO.md).

- **Simple**: `threshold` + `sensitivity` (0…1), центр `0.5` = стандарт.
- **Detailed**: только **5 значений групп** (0…200); стандартное значение — `100`.
- **Порог и чувствительность** — только на вкладке Simple. Detailed их не содержит.

---

## Эндпоинты

| Слой | PUT/GET | Тело |
|------|---------|------|
| Simple | `/analysis-settings/{profile}/simple` | `threshold`, `sensitivity` |
| Detailed | `/analysis-settings/{profile}/strengths` | 5 сил (без threshold/sensitivity) |

Ответ: `knobs`, `settings`, `defaults`, `overrides`.

Simple и detailed **сохраняются вместе** по `product_type`.

---

## Simple (2 ручки)

| API-поле | Название | Пояснение |
|----------|----------|-----------|
| `threshold` | Порог брака | Выше — реже брак |
| `sensitivity` | Чувствительность | `0.5` = стандарт; меньше — грубее, больше — чутче |

---

## Detailed (5 сил)

| API-поле | Название | Пояснение |
|----------|----------|-----------|
| `noise_tolerance` | Сила · шум | Значение группы умножается на общую чувствительность |
| `scratch_sensitivity` | Сила · царапины | `0` = итоговая чувствительность группы 0% |
| `edge_suppression` | Сила · края | `100` = вся общая чувствительность |
| `text_handling` | Сила · текст | |
| `preprocess_strength` | Сила · предобработка | |

### Края слайдеров (силы, 0–200)

| | 0 | 50 | 100 | 200 |
|---|---|---|---|---|
| Сила группы | 0% от общей чувствительности | 50% от общей чувствительности | вся общая чувствительность | удвоенная общая чувствительность, итог до 200% |

## Заголовки вкладок

| Вкладка | Заголовок |
|---------|-----------|
| simple | Быстрая настройка |

|-----|--------|
| `422` | Порог вне `(0, 1]`; sensitivity вне `[0, 1]`; силы вне `[0, 200]` |
| `400` | Ошибка expand |
