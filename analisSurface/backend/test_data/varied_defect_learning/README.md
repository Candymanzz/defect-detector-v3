# Набор разных дефектов

Каждое семейство независимо сохраняется как допустимая норма. Проверяются перенос, масштабы 70% и 45%, ослабленный контраст, две копии, увеличение до 145% и все перекрёстные пары разных форм.

Запуск из `analisSurface/backend`:

```powershell
.\.venv\Scripts\python.exe scripts\validate_varied_defect_learning.py
```
