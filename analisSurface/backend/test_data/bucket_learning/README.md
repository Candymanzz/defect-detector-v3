# Набор проверки обучаемой нормы на ведре

Исходный фотокадр ведра создан встроенным генератором изображений. Все
проверочные варианты построены детерминированно поверх одной и той же копии:
кроме нарисованного дефекта остальные пиксели не меняются.

## Ручная проверка

Откройте `http://127.0.0.1:8000/local-inspection-test` и используйте:

1. `reference.png` как эталон;
2. `learn_seed.png` как первый текущий кадр;
3. сохраните L-образный дефект из `learn_seed.png` как допустимую норму;
4. по очереди загружайте `good_*.png` и `bad_*.png`.

Ожидание по именам:

- `good_*.png` должно давать `ГОДЕН` после обучения;
- `bad_*.png` должно сохранять `БРАК`;
- `bad_08_normal_plus_x.png` содержит одновременно допустимую норму и новый
  X-дефект: L должна исключиться, X должен оставить итог `БРАК`.

## Автоматическая проверка

Из `analisSurface/backend`:

```powershell
.\.venv\Scripts\python.exe scripts\generate_bucket_learning_dataset.py
```

Скрипт заново создаёт варианты, использует отдельную временную память нормы и
обновляет `REPORT.md`, `report.json`, `report.csv` и `contact_sheet.jpg`.
Код возврата `0` означает полное совпадение с ожиданиями, `2` — наличие
проваленных сценариев.

Текущий результат приведён в `REPORT.md`. Не меняйте ожидаемые статусы только
ради зелёного отчёта: провалы предназначены для выявления ложного пропуска или
ложного брака алгоритма.
