# Компактные отличия и остатки позиционирования

`residuals.npz` содержит пять небольших lossless gray-кропов исходной карты
отличий пуска 9 октября 2026, с контекстом 32 пикселя вокруг каждой области.
Исходные review, координаты и SHA-256 карты перечислены в `sources.json`.

Дефекты камер 1 и 3 инспекции 195 подтверждены оператором. Камера 3 пропускала
дефект при пороге 0.25. Другие кропы — контроль добавочного усиления: полоса
кромки камеры 6 и остатки контуров печати. Эти примеры не являются полной
разметкой остальных изделий и не подтверждают, что весь кадр был годным.

Тест проверяет только новую оценку компактных отличий. Полный пересчёт
200 сохранённых review с актуальными нормами и FP-зонами выполнен отдельно.
