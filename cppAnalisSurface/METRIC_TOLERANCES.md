# Допуски проворота и вертикального смещения

2026-11-02, ветка `mm-cpp`. Пересчёт единиц и приблизительные масштабы камер взяты из `ppc-reserv` (`f1ae20b8`).

- «Допуск проворота» — допустимое горизонтальное перемещение этикетки, поле `horizontal_shift_tolerance_mm`.
- «Допуск вертикального смещения» — поле `vertical_shift_tolerance_mm`.
- Диапазон 0..10 мм, шаг интерфейса 0.05 мм. Миллиметры пока приблизительные; калибровка на машине уточняет масштаб.

Проворот оценивается по видимому горизонтальному смещению; алгоритм не измеряет угол поворота цилиндра.
Цифровое изменение разрешения учитывается; перспектива и изменение оптического масштаба требуют измерений на машине.

Текущие глобальные пределы смещения и локальное ослабление сравнения сохраняют независимость.
Мм управляют только `max_alignment_shift_x/y` в расчёте; «Ослабление сравнения» остаётся отдельным общим
пиксельным допуском. Изменение мм не расширяет min/max-конверт и не скрывает дополнительные дефекты.
Расчёт аномалии, heatmap, чувствительность и стык остаются текущими для `mm-cpp`.

Приблизительные мм/пиксель для 1224×1024:

| Камера | Горизонталь | Вертикаль |
|---|---:|---:|
| 0 | 0.25 | 0.33 |
| 1 | 0.28 | 0.32 |
| 2 | 0.31 | 0.31 |
| 3 | 0.25 | 0.32 |
| 4 | 0.27 | 0.34 |
| 5 | 0.27 | 0.34 |
| 6 | 0.25 | 0.33 |
| 7 | 0.22 | 0.23 |
| 8 | 0.22 | 0.32 |
| 9 | 0.28 | 0.33 |

`mmPerPixelX = estimateX * 1224 / width`, `mmPerPixelY = estimateY * 1024 / height`.
При выполнении инспекции `maxAlignmentShiftX = horizontalMm / mmPerPixelX`, аналогично Y.
Уменьшение масштаба анализа не меняет заданный физический предел, но влияет на точность оценки смещения.
Нормализованная калибровка `calibration` из `ppc-reserv` поддерживается через API; отдельная карточка калибровки не требуется.

Старые профили получают начальные мм из существующих глобальных px-пределов с масштабом своей камеры (максимум 10 мм).
Например, 12 px камеры 4 становятся 3.24 мм по горизонтали и 4.08 мм по вертикали.
Сохраняются текущая миграция старых пиксельных профилей и совместимость прямых `max_alignment_shift_x/y` overrides.
Такой override отменяет мм только соответствующей оси запроса. `shift_tolerance_x/y` управляют только сравнением.

Камера передаётся отдельно от имени профиля: `/settings/custom-profile?camera_id=4`, `camera_id` в `/inspect-shm`.
При общем сохранении UI передаёт мм и ослабление сравнения, сохраняя масштаб/калибровку каждой камеры отдельно.
Ответ инспекции содержит `shift_mm`, `shift_raw_mm`, `shift_limit_mm`, `mm_per_pixel`, `metric_scale_source`, `analysis_pixel_mm`.
